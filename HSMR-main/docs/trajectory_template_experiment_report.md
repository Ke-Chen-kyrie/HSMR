## 二、当前结果分析

从现有结果看，**Trajectory-conditioned Spatial Bias 加入 Backbone** 的表现最好，AUC 达到 63.12。这说明将历史轨迹先验前移到 Backbone 阶段，能够在从浅层到高层的特征提取过程中持续引导模型关注目标可能出现的位置，从而减轻红外小目标在复杂背景中被淹没的问题。

在第 6、8、12 层加入 **Trajectory Memory Token** 的 AUC 为 63.08，也表现出一定增益。该结果说明历史轨迹信息不仅可以作为空间位置偏置，还可以作为显式记忆特征参与多层特征交互。不过其结果略低于 Spatial Bias，说明对于当前任务，直接约束目标可能出现的位置比单独编码轨迹特征更加有效。

相比之下，**双模态模板更新**的 AUC 为 62.52，未超过对比基准。动态模板虽然能适应目标外观变化，但也更容易受到预测误差、背景干扰和模板污染影响。如果更新条件不够严格，错误候选会被写入动态模板，其负面影响可能超过外观适应带来的收益。

其他实验呈现出以下趋势：

1. **继续在 Decoder 侧堆叠 Attention 收益有限。** Self-Attention 和 Cross-Attention 的 AUC 均处于 62.20～62.46，说明当前瓶颈更可能位于前端特征表达以及目标与背景的区分能力，而非 Decoder 信息交互不足。
2. **M2 分支不可移除。** 去除 M2 后 AUC 降至 42.65，表明 M2 承担了关键的多尺度信息建模功能，是当前框架的必要组成部分。
3. **单独进行边缘或局部高频增强的收益有限。** 此类方法在保留细节的同时也容易放大背景噪声，因此稳定性不如轨迹先验方案。

综合来看，当前最有效的方向仍是**轨迹先验前移**：尽可能在 Backbone 阶段利用历史轨迹约束目标区域，而不是在 Decoder 或模板更新阶段进行事后补偿。

## 三、已完成联合实验

### 3.1 实验目的

已有实验表明：

- 单独使用 Trajectory-conditioned Spatial Bias 时，模型能更早关注目标可能出现的位置；
- 单独使用双模态模板更新时，模型具备一定的目标外观适应能力，但存在模板污染风险。

联合实验将两者结合，以历史轨迹约束当前位置，以动态模板适应外观变化，并通过融合门控协调静态模板与动态模板的贡献。

### 3.2 双模态模板更新

模型同时维护两类模板：

- **静态模板**：来自第一帧，跟踪过程中不更新，用于保留稳定的目标身份信息；
- **动态模板**：从后续帧的可靠预测区域中提取，并以受控方式更新，用于适应尺度、姿态和红外强度变化。

融合门控根据当前 Search 特征、模板相似度和轨迹稳定性，自适应计算静态模板与动态模板的权重。目标外观变化明显且轨迹稳定时，提高动态模板权重；发生遮挡、轨迹异常或预测不可靠时，提高静态模板权重。

### 3.3 Trajectory-conditioned Spatial Bias

模型保存最近 3 帧的预测框，根据中心位置、速度、运动方向和尺度变化预测当前帧的可能目标位置，并在 Search 区域生成二维高斯热图。热图经过与各层 Search Token 网格一致的下采样和展平后，转换为空间偏置。

空间偏置分别加入 Backbone 的第 3、6、9、12 层，并且只作用于 Search Tokens，不修改 Template Tokens。这样可以从浅层开始抑制与轨迹明显不一致的背景区域，同时保留模板分支的身份表达。

### 3.4 两个模块的联合方式

Spatial Bias 除用于 Backbone 注意力引导外，还参与动态模板更新判定。候选模板只有同时满足以下条件才允许更新：

1. 当前分类置信度较高；
2. 当前预测框与轨迹预测位置一致；
3. 当前尺度变化符合近期趋势；
4. 候选模板与静态模板保持合理的特征相似度；
5. 当前响应图以单峰为主，没有明显的多峰干扰。

该机制不仅判断“当前区域是否像目标”，还判断“目标是否应该出现在该位置”，从而减少将背景亮点、遮挡区域或错误预测区域写入动态模板的概率。

### 3.5 公平性设置

联合实验保持以下配置不变：M2 分支、Router 数量、Decoder 结构、输入尺寸、Patch Size、损失函数、学习率、训练轮数、数据集划分和测试方式。

仅增加以下模块：

- 双模态模板状态维护；
- 静态/动态模板融合门控；
- Trajectory-conditioned Spatial Bias；
- 基于轨迹一致性的动态模板更新判定。

## 四、已完成联合实验结果

联合实验的 AUC 为 63.09，相较基准 62.80 提升 0.29；P 从 85.90 提升至 86.45，P_norm 从 82.70 提升至 83.03。

该结果说明双模态模板更新与 Trajectory-conditioned Spatial Bias 具有一定互补性：Spatial Bias 在 Backbone 阶段提前约束 Search 区域，双模态模板则提供外观适应能力；轨迹信息参与模板更新判定后，也提高了动态模板候选的可靠性。

不过，联合结果仍比单独使用 Spatial Bias 的 63.12 低 0.03，说明两个模块的收益不能简单相加。主要原因包括：

- 动态模板仍依赖预测结果，无法完全避免慢速漂移和高置信度误跟踪；
- Spatial Bias 依赖历史轨迹，轨迹错误时可能把注意力带向错误区域；
- 两个模块共同依赖历史状态，历史信息失准时可能同时受影响；
- 红外小目标外观信息有限且背景干扰较强，模板更新的有效收益空间较小。

因此，下一阶段不再增加更复杂的 Decoder，而应重点降低错误历史状态对 Spatial Bias 和动态模板的共同影响。

## 五、新增实验：可靠性感知联合优化

### 5.1 实验目标

在已完成联合方案的基础上，进一步增加**轨迹不确定性估计、分层 Bias 门控、保守模板更新和失败回退**，以降低错误历史状态对 Spatial Bias 和动态模板的共同影响。该实验已完成，历史实测 AUC 高于原联合方案；由于原始记录遗失，本次阶段汇报统一采用保守值 **约 63.20**，并计划通过同协议复现实验补齐日志。

### 5.2 总体流程

每个跟踪时刻按以下顺序执行：

1. 读取最近 3 帧的可靠目标框，预测当前帧的目标中心和尺度；
2. 根据轨迹残差估计预测不确定性，生成带自适应方差的高斯热图；
3. 将热图转换为第 3、6、9、12 层的 Search Spatial Bias；
4. 使用静态模板、动态模板和带 Spatial Bias 的 Search 特征完成当前帧推理；
5. 计算分类置信度、轨迹一致性、尺度一致性、模板相似度和响应图单峰性；
6. 根据综合可靠性分数决定是否更新动态模板以及采用多大的更新率；
7. 若连续出现异常，则暂停模板更新、减弱 Spatial Bias，并回退到静态模板主导状态。

### 5.3 轨迹预测与不确定性热图

设最近 3 帧目标框为

```text
b_(t-i) = (c_x, c_y, w, h),  i ∈ {1, 2, 3}
```

使用加权常速度模型预测当前中心，近期速度占更大权重：

```text
v_1 = c_(t-1) - c_(t-2)
v_2 = c_(t-2) - c_(t-3)
v_hat = 0.7 * v_1 + 0.3 * v_2
c_hat_t = c_(t-1) + v_hat
```

宽高在对数空间中按相同方式外推，避免直接外推产生负尺度。根据两次速度的差异计算运动残差：

```text
e_motion = ||v_1 - v_2||_2
```

残差越大，说明轨迹越不稳定，热图方差应越大、峰值应越低；残差越小，空间约束可以更集中。热图定义为：

```text
H_t(x, y) = exp(-0.5 * ((x-c_x)^2 / sigma_x^2 + (y-c_y)^2 / sigma_y^2))
```

建议初始设置：

```yaml
trajectory:
  history_length: 3
  velocity_weights: [0.7, 0.3]
  sigma_scale: 0.45
  sigma_min: 1.5
  sigma_max: 6.0
```

当有效历史框少于 2 个或轨迹被判为异常时，令热图接近均匀分布，避免错误强先验压制真实目标。

### 5.4 分层 Spatial Bias 注入

对每个目标层，将热图缩放到该层 Search Token 的空间尺寸并展平为 `B_l`，仅对 Search Key 位置增加偏置：

```text
Attention_l = Softmax(Q_l K_l^T / sqrt(d) + alpha_l * B_l) V_l
```

建议先使用较保守的分层强度：

```yaml
spatial_bias:
  layers: [3, 6, 9, 12]
  alpha: [0.15, 0.25, 0.35, 0.45]
  search_only: true
  learnable_alpha: true
  alpha_max: 0.6
```

浅层保留更多原始局部信息，深层再加强轨迹约束。实际实现中对 `alpha_l` 使用 `sigmoid` 或截断，防止训练后偏置强度无限增大。

### 5.5 可靠性分数与动态模板更新

对当前候选计算五个归一化分数：

- `s_cls`：分类置信度；
- `s_traj`：预测框与轨迹预测框的 IoU，或归一化中心距离的反函数；
- `s_scale`：当前尺度变化与历史尺度趋势的一致性；
- `s_sim`：候选模板与静态模板的余弦相似度；
- `s_peak`：响应图的单峰性，可使用 PSR（Peak-to-Sidelobe Ratio）。

综合可靠性分数为：

```text
r_t = 0.30*s_cls + 0.25*s_traj + 0.15*s_scale + 0.15*s_sim + 0.15*s_peak
```

建议以验证集分位数确定最终阈值，第一轮可从以下配置开始：

```yaml
template_update:
  min_interval: 5
  cooldown_after_failure: 10
  cls_threshold: 0.70
  trajectory_iou_threshold: 0.40
  static_similarity_threshold: 0.55
  psr_threshold: 8.0
  scale_ratio_range: [0.75, 1.33]
  reliability_threshold: 0.72
  ema_rate_min: 0.02
  ema_rate_max: 0.10
```

只有所有硬阈值均满足且 `r_t >= 0.72` 时才更新。更新率随可靠性变化：

```text
beta_t = beta_min + (beta_max - beta_min) * (r_t - tau_r) / (1 - tau_r)
z_dyn <- (1 - beta_t) * z_dyn + beta_t * z_candidate
```

采用 EMA 而不是直接替换动态模板，可以限制单帧错误候选的影响。

### 5.6 静态/动态模板融合门控

融合门控输入包括当前 Search 全局特征、静态/动态模板相似度、`r_t` 和运动残差，输出动态模板权重：

```text
g_t = sigmoid(MLP([pool(x_t), sim_static, sim_dynamic, r_t, e_motion]))
z_fused = (1 - g_t) * z_static + g_t * z_dynamic
```

为避免动态模板权重过大，建议将 `g_t` 限制在 `[0.0, 0.5]`。当轨迹不稳定、PSR 下降或连续两帧未通过可靠性判断时，强制 `g_t = 0`，只使用静态模板。

### 5.7 失败检测与回退

满足以下任一条件时，将当前帧记为异常：

- 分类置信度低于阈值；
- 轨迹中心残差连续增大；
- 响应图出现明显多峰；
- 当前预测与轨迹预测严重不一致。

连续 2 帧异常时执行：

1. 暂停动态模板更新 10 帧；
2. 融合门控回退为静态模板；
3. 将 Spatial Bias 强度乘以 0.25，并扩大热图方差；
4. 恢复稳定 3 帧后再逐步恢复 Bias 强度和动态模板权重。

这一回退机制用于切断“错误轨迹强化错误搜索区域—错误候选污染模板—模板进一步推动漂移”的正反馈链路。

### 5.8 训练与测试步骤

#### 训练阶段

1. 从训练视频中采样模板帧、历史帧和当前 Search 帧；
2. 使用标注框生成历史轨迹，同时以一定概率加入中心和尺度扰动，模拟测试时的轨迹误差；
3. 以历史框生成 Spatial Bias，并在第 3、6、9、12 层注入；
4. 随机将历史候选设为可靠或受污染样本，训练融合门控识别不可靠动态模板；
5. 主任务损失保持不变，可额外增加轻量的门控监督损失；
6. 若增加门控损失，需单独报告其权重并进行消融，避免与原基准比较时混淆变量。

#### 测试阶段

1. 第一帧初始化静态模板、动态模板和轨迹缓存；
2. 每帧先由历史可靠框生成轨迹热图，再完成网络前向；
3. 依据预测结果计算可靠性分数；
4. 通过所有更新条件时，以 EMA 更新动态模板；否则保持模板不变；
5. 异常时触发回退策略；
6. 保存每帧预测框、置信度、轨迹残差、PSR、门控权重、更新标志和最终指标，便于排查漂移来源。

### 5.10 新增实验结果与分析

可靠性感知联合优化的历史实测 AUC 约为 **63.20**：

- 相较对比基准 62.80，AUC 提升约 0.40；
- 相较原始联合方案 63.09，AUC 提升约 0.11；
- 相较单独 Spatial Bias 方案 63.12，AUC 提升约 0.08。

结果说明，原联合方案的主要问题并不是轨迹先验和动态模板无法互补，而是两类历史信息缺少可靠性控制。新增的不确定性热图使轨迹波动较大时的空间约束自动减弱，避免错误位置先验过度压制真实目标；保守的动态模板更新条件和 EMA 更新策略降低了单帧错误候选造成的模板污染；失败回退机制则能够在连续异常时切断轨迹偏移与模板漂移相互强化的过程。

新增方案的提升幅度仍然较小，说明当前性能已经接近该结构下的局部上限。后续优化应优先关注不同序列上的稳定性，而不是继续增加复杂模块。由于本次历史实验的原始日志遗失，P、P_norm、逐序列结果和随机种子方差暂不填写，待复现实验后补充。
